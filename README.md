**纯落地、代理、测试环境**：LAXLite-One（¥8.88/月起，5Gbps 端口）和 SGLite-One（¥10.42/月起）是这一档最省的选择。5Gbps 端口不代表你能跑满，共享带宽下实际速度看同机房其他用户，但日常中转绰绰有余。

**看日区流媒体**：官方说明写日本机房支持当地流媒体解锁，JPHyper 系列在带宽和价格上都比 JPPro 划算，JPPro 贵在路由调优而不是流量。

线路名词顺带解释清楚，省得被商品页的缩写绕进去：

- **CN2 GIA**：电信精品网 AS4809，去回程都走 CN2，晚高峰最稳，价格最高。
- **CN2 GT**：只有出国段走 CN2，国内段走 163 骨干，比 GIA 便宜，稳定性差一档。商家只写「CN2」没写 GIA 的，按 GT 预期。
- **9929**：联通精品网 AS9929，联通用户效果最好。Akile 的 DE9929 就是这类。
- **4837**：联通普通骨干 AS4837，带宽便宜量大，晚高峰可能拥堵。Akile 的 LAX4837 走这条。
- **CMIN2 / CMI**：移动精品网 AS58807 和移动国际普通出口 AS58453，前者优于后者。
- **IIJ**：日本主流商用骨干，日本本地和回国都算中上。

Akile 的 Lite 系列是普通国际线路，官方没有标「三网优化」，别指望它晚高峰和 CN2 GIA 一个表现。想要回国优化又不想花 GIA 的钱，RAKsmart 的硅谷精品 CN2 秒杀款 $4.99/月（2 核 2GB / 50GB HDD / 1Gbps / 1TB 流量）是这一档的参照物，代价是每天限量 20 台、不可叠加优惠券、不支持升降级。

同样没有公开条款。年付之前用工单问清楚退款窗口，尤其是限量款，很多商家对活动机型不设退款。

**月付还是年付？**
不确定能不能长期用就月付。JPHyper-Mini 这种年付省 16.7% 的，确定用满一年再上年付；省下来的钱不够覆盖一次迁移的时间成本。

**要不要等 11 月 27 日当天？**
你想要的机房还有库存，现在买；库存显示个位数，更别等。黑五当天的价格变动幅度，通常小于你想要的那款售罄的概率。

**香港机房能跑 Claude Code 吗？**
不能。香港不在 Anthropic 的支持地区内，选日本、新加坡、美国、英国或德国的机房。
